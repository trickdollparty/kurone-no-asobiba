# 競馬ポートフォリオ最適化＆リスクヘッジシミュレーター

競馬における**「攻め（高配当・三連単など）」**と**「守り（元金回収・馬連/ワイド/複勝など）」**を組み合わせたハイブリッド投資戦略、およびオッズ連動の傾斜配分をシミュレーション・最適計算するStreamlitベースのWebアプリケーションです。

---

## 🌟 主な機能と特徴

### 1. 2段階オンデマンド・マルチソース対応データ取得
* **方式A（段階的オンデマンド取得）:**
  * レース一覧画面を開いた初回、または「🔄 当月のレース一覧を手動更新」ボタンを押下した時のみ当月一覧を取得。
  * レースを選択した時のみ、該当レースの出馬表・単勝オッズを単発取得（セッションキャッシュによる通信最小化）。
  * netkeiba特有の `EUC-JP` / `UTF-8` 文字コード混在を自動判別デコードし、文字化けを完全防止。
* **方式B（コピペ一発スマートパーサー）:**
  * JRA公式やnetkeibaの出馬表画面をブラウザで全選択コピーして貼り付けるだけで、「枠番・馬番・馬名・騎手・単勝オッズ・人気」を正規表現とヒューリスティック解析により一発自動取り込み。
* **方式C（内蔵プリセット＆JSON/CSVインポート）:**
  * 秋華賞、菊花賞、天皇賞(秋)、富士ステークス等のリアルな出馬表データをプリセットとして内蔵。
  * 外部通信ができない環境でも即座にテスト・利用可能。
* **ハービルの公式に基づく複合馬券オッズ推計:**
  * 出馬表の単勝オッズから支持率を逆算し、JRA控除率を考慮したハービル（Harville）の公式の簡易近似により、馬連・ワイド（下限/上限）・馬単・三連複・三連単の想定オッズを自動算出。

### 2. 高速資金配分エンジン（NumPy＋独自の貪欲法）
* **100円整数制約:** 全買い目の購入金額は100円単位（100の倍数）かつ、総予算を1円たりとも超過しません（$\sum \le \text{total\_budget}$）。
* **3つの戦略モード:**
  1. **ハイブリッド戦略 (`hybrid`):**
     * 守り枠（`defense`）のどれか1点でも的中した際に総予算 $\times$ 目標回収率を確実に回収する金額を自動配分。
     * 残予算を攻め枠（`offense`）に傾斜/均等配分。
     * 守り枠のみで予算超過した場合は `is_bankrupt=True` となり、追加予算額や目標回収率の引き下げ目安を自動提案。
  2. **均等払戻（傾斜配分）戦略 (`equal_payout`):**
     * 合成オッズに基づき、全買い目で的中時の想定払戻金が極力均等になるよう100円単位で最適配分。
  3. **元返し保険戦略 (`insurance`):**
     * 守り枠の最有力1点で元金回収ヘッジを行い、残余予算を攻め枠に配分。
* **余剰金貪欲配分（Greedy Algorithm）:**
  * 配分後の端数（余剰金）は「最低払戻の底上げ（`boost_min_payout`）」または「最大オッズ優先（`max_odds`）」に従い、100円ステップで自動配分。
* **リスク判定・アラート:**
  * トリガミ検知（投資額を下回る買い目の特定と不足額の算出）。
  * 合成オッズ低下警告（指定閾値未満でアラート表示）。

### 3. 着順シミュレーション＆結果検証
* 仮想の確定着順（1〜3着）を選択すると、複数的中（ワイド3点、複勝3点、馬連＋ワイド等）を完全に合算評価。
* 払戻金（最小〜最大）、純利益、最終回収率をリアルタイム表示。
* **4シナリオ損益マトリクス:**
  * 「守りのみ的中」「攻めのみ的中」「ダブル的中」「全ハズレ」の4パターンの損益レンジと回収率を自動算出。

### 4. デジタル庁デザインシステム準拠 UI/UX
* デジタル庁ブルー（`#0017C1`）、高コントラストテキスト（`#1A1A1C`）、等幅・表組数字（`font-variant-numeric: tabular-nums;`）を適用。
* JRA標準枠番カラー（1枠白〜8枠桃）を視覚的に再現。
* 最新の `@st.fragment` デコレータにより、テーブル編集やスライダー操作時の部分再描画を実現（画面全体のスクロール飛びを防止）。
* `st.data_editor` と `st.column_config` による直感的な予想印・オッズ・ロールの編集。

## 🚀 起動手順

### 1. 依存ライブラリのインストール
```bash
pip install -r requirements.txt
```

### 2. アプリケーションの起動
```bash
streamlit run app.py
```
ブラウザが自動的に開き、`http://localhost:8501` にてシミュレーターが利用可能になります。

### 3. テストの実行
```bash
pytest tests/test_core.py -v
```

## 💡 使い方・画面遷移

### 【フェーズ1：レース選択 ＆ 出馬表確認】
1. **タブA（当月レース一覧）**、**タブB（URL/ID取得）**、または**タブC（出馬表コピペ）**から対象レースを選択。
2. 出馬表テーブルで予想印（◎, ○, ▲, △, ☆）を付けたり、単勝オッズを編集。
3. **「🚀 このレースでシミュレーションを開始する」**（または「⚡ サンプル買い目付きでシミュレーションを開始する」）をクリック。

### 【フェーズ2：ポートフォリオ構築 ＆ シミュレーション】
1. **サイドバー:** 総予算、戦略モード（ハイブリッド/均等払戻/元返し保険）、守り目標回収率を設定。
2. **STEP 1（買い目構築）:** 
   * 券種（ワイド・馬連・三連複など）を選択し、1〜3頭目を指定して「フォーメーションを展開して追加」または「印から推奨買い目を自動追加」。
   * 「買い目編集」タブで、各買い目の役割（守り `defense` / 攻め `offense`）や想定オッズを微調整。
3. **STEP 2（配分ダッシュボード）:** 
   * 自動計算された投資額、残予算、合成オッズ、KPIカード、配分テーブル、Plotly純利益チャート、4シナリオ損益マトリクスを確認。
4. **STEP 3（着順シミュレーション）:**
   * 1着・2着・3着の馬番を選択し、的中時の払戻金合計や最終回収率を即座にシミュレーション。
